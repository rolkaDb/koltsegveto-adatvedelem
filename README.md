# Költségvető — adatvédelmi tájékoztató

Ez a repó egyetlen dolgot tartalmaz: a **Költségvető** Android-alkalmazás
adatvédelmi tájékoztatóját, amit a Google Play Console nyilvános webcímként kér.

A tájékoztató itt olvasható: <https://rolkadb.github.io/koltsegveto-adatvedelem/>

Az alkalmazás forráskódja külön, privát repóban van — ide csak az a dokumentum
kerül ki, aminek amúgy is nyilvánosnak kell lennie.

## Szerkesztés

Az `index.html` a teljes dokumentum, külső függőség nélkül. Módosítás után elég
a `main` ágra pusholni: a GitHub Pages pár percen belül frissíti az oldalt.

Ha a tartalom érdemben változik, a dokumentum két helyén szereplő
**hatálybalépési dátumot** is frissíteni kell (a fejlécben és a lábjegyzetben).
